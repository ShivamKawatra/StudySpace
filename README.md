# StudySpace 📚

**StudySpace** is a comprehensive academic resource platform designed specifically for Diploma Computer Science Engineering (CSE) students. It provides a centralized hub for accessing syllabus, study notes, lecture videos, and previous year questions.

## 🌟 Features

- **📖 Comprehensive Syllabus**: Complete syllabus for all semesters with detailed course outlines
- **📝 Study Notes**: Well-organized study materials for easy understanding
- **🎥 Video Lectures**: Access to educational content for all subjects
- **❓ Previous Year Questions (PYQs)**: Practice with past examination papers
- **📱 Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **🎨 Modern UI**: Clean and intuitive user interface with smooth animations

## 🚀 Live Demo

Visit the live website: [StudySpace](https://shivamkawatra.github.io/StudySpace/)

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with animations and responsive design
- **Bootstrap 5**: CSS framework for responsive layout
- **Font Awesome**: Icon library for enhanced UI
- **JavaScript**: Interactive features and animations
